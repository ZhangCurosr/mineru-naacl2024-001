# 论文速读：A-Wolf-in-Sheep-s-Clothing-Generalized-Nested-Jailbreak-Prom

## 一句话总结
提出了 ReNeLLM 框架，将大模型越狱攻击泛化为**提示词改写**与**场景嵌套**两个自动化步骤，仅利用 LLM 自身即可高效生成语义连贯的对抗提示，在多个开源/闭源模型上实现了高攻击成功率与显著降低的时间成本。

## 研究问题与动机
1. **手动越狱提示成本高且易失效**：如 DAN 等需人工精心构造，且随模型安全对齐迭代迅速过时。
2. **学习式攻击依赖白盒模型且攻击词无意义**：如 GCG 在另一白盒模型上搜索对抗后缀，耗时漫长，生成的后缀缺乏语义，难以迁移至 Claude-2 等商业闭源模型。
3. **现有防御方法对泛化攻击识别不足**：主流拦截策略（关键词过滤、困惑度过滤等）难以应对经过语义保留改写与任务上下文包裹的隐蔽提示。
4. **缺乏对防御失效机理的系统性解释**：业界尚未明确揭示 LLM 在面对此类泛化攻击时安全优先级被覆盖的根本原因。

## 核心贡献（创新点）
1. **首个通用型自动越狱框架 ReNeLLM**：将攻击过程泛化为改写+嵌套两步，区别于传统依赖白盒梯度搜索或固定模板的方法，完全由 LLM 自主驱动生成。
2. **提出语义保留的六类提示词改写函数**：与现有直接构造后缀的方法本质不同，本文通过句式重组、拼写扰动、部分翻译等语言学操作保持意图连贯，大幅提升对抗提示的“自然度”与渗透性。
3. **设计基于通用任务场景的嵌套策略**：引入代码补全、表格填充、文本续写三类与预训练/SFT数据高度对齐的场景，利用 LLM 对任务指令的响应惯性转移其注意力焦点。
4. **从注意力优先级偏移角度解释防御失效机制**：通过梯度注意力可视化揭示 LLM 在处理越狱提示时从“安全优先”向“有用性优先”的转变，并据此提出轻量级 prompt 级防御方案。

## 方法详解
- **形式化定义**：给定待测模型 $LLM_{mut}$ 与初始有害提示 $X$，目标是在有限策略空间中找到最优策略 $S^*$，最大化危害评估器 $LLM_{eval}$ 的输出概率：$\underset{S}{\mathrm{argmax}} \ LLM_{eval}(LLM_{mut}(S(X)))$。
- **Prompt Rewriting（提示词改写）**：设计 6 类保语义改写函数：(1) 缩写 paraphrase（≤6词，生成5个候选随机选1个）；(2) 语序重组；(3) 敏感词拼写错误；(4) 插入无意义字符/外语；(5) 部分翻译（中英混合）；(6) 口语/方言替换。每次随机选取 1~6 个函数并按随机顺序依次执行。
- **Scenario Nesting（场景嵌套）**：从三个通用场景（Code Completion、Table Filling、Text Continuation）中随机选择一个，将改写后的提示嵌入任务的空白占位符（类似完形填空），利用 SFT 训练形成的指令遵循惯性引导模型生成内容。
- **迭代搜索流程**：使用 GPT-3.5 作为改写器与评估器，最大迭代次数 $T=20$。若 $LLM_{eval}$ 判定嵌套后提示仍具危害性且目标模型输出被判定为有害，则输出对抗提示；否则重置提示进入下一轮随机组合搜索。

## 实验与结果
- **数据集**：Harmful Behaviors（520 条有害行为提示），按 OpenAI 政策由 GPT-4 分类为 7 个类别（Illegal Activity, Hate Speech, Malware 等）。
- **评估模型**：GPT-3.5, GPT-4, Claude-1, Claude-2, Llama2-7b/13b/70b。
- **评估指标**：KW-ASR（关键词匹配）、GPT-ASR（GPT-4 语义评估）、ASR-E（6 个候选提示集成）、TCPS（单样本平均生成耗时）。
- **基线对比**：GCG、AutoDAN、PAIR。
- **核心结果**：
  - ReNeLLM 在全部模型上取得最优 ASR，GPT-3.5 达 86.9%，GPT-4 达 58.9%，Claude-1 达 90.0%，Claude-2 达 69.6%，Llama2-7b 达 51.2%；集成后（ASR-E）逼近 100%。
  - 时间效率显著提升：TCPS 为 132.03s，较 GCG（564.53s）降低 76.61%，较 AutoDAN（955.80s）降低 86.19%。
  - 攻击可迁移性强：以 Claude-2 为目标训练生成的模式可成功攻击其他架构与规模模型。
- **防御实验**：OpenAI Moderation 拦截率为 0%；PPL Filter 仅降低 4.1%；RA-LLM 最多降低 28%（Llama2）/24%（Claude-2），但测试开销大。基于优先安全+审查流程的 prompt 防御可将 ASR 降至接近 0%。

## 相关工作脉络
1. **DAN 等手动越狱**：依赖人工构造角色扮演/规则覆盖提示，策略固定、易被更新修复，本文方法自动化且持续适应新模型。
2. **GCG（Zou et al., 2023）**：在白盒模型上通过离散优化搜索对抗后缀，后缀无意义且耗时；本文完全放弃后缀优化，改用语义保留的语言学改写。
3. **AutoDAN（Liu et al., 2023）**：基于分层遗传算法生成语义连贯提示，但优化过程昂贵；本文用随机采样+LLM 自评估替代进化搜索，大幅降本增效。
4. **PAIR（Chao et al., 2023）**：利用攻击者 LLM 查询目标模型并 refine 提示，属于黑盒 query-based 方法；本文不依赖多轮交互查询，仅通过改写+嵌套直接构造。
5. **防御方法（PPL Filter, RA-LLM 等）**：现有防御侧重过滤异常 token 或概率分布；本文揭示防御失效源于指令优先级偏移，提出从 system prompt 重设优先级与审查流程的干预路径。

## 局限性与未来方向
- **场景嵌套具有固定性**：当前仅使用 3 种通用场景，静态模式可能被针对性过滤或安全对齐；未来可由 LLM 自动生成更多样化的嵌套场景。
- **数据集以英文为主**：跨语言泛化能力未充分验证，部分改写操作（如中英混合）在其他语言中可能不适用。
- **搜索策略为随机采样**：函数数量与顺序的随机选择并非最优，未来可引入强化学习或贝叶斯优化提升搜索效率。
- **依赖商业 LLM 作为生成/评估组件**：使用 GPT-3.5/GPT-4/Claude-2 成本较高，探索基于较小开源模型的等效性能是重要方向。

## 研究启发与可借鉴点
1. **改写+嵌套范式可迁移至鲁棒性评测**：该“形式扰动保语义+任务上下文包裹”的思路可用于评测其他指令遵循型 AI 系统（如代码助手、客服机器人）的安全边界。
2. **注意力优先级偏移诊断工具**：梯度注意力可视化揭示“安全 vs 有用性”优先级切换的机制，可作为团队内部安全对齐效果评估的可解释诊断手段。
3. **零成本 prompt 级防御有效性验证**：仅通过修改 system prompt（明确 Prioritize Safety + Scrutiny Reminder）即可将多数模型 ASR 压至接近 0%，为快速部署防御提供了低成本替代方案。
4. **多维度评估指标体系**：同时报告 KW-ASR、GPT-ASR、ASR-E 与 TCPS，兼顾攻击强度、语义真实性与工程效率，可作为后续 adversarial prompt 研究的标准化评测范式。

## 关键术语表
- **Jailbreak Prompt**：刻意构造的对抗性输入，用于绕过 LLM 的安全对齐机制诱使其生成有害内容。
- **Prompt Rewriting**：在不改变原始提示核心语义的前提下，通过缩写、拼写扰动、语序调整等语言学操作变换其表达形式。
- **Scenario Nesting**：将改写后的有害提示嵌入代码补全、表格填充、文本续写等通用 SFT 任务场景中，利用模型的任务惯性掩盖真实意图。
- **KW-ASR**：基于关键词字典匹配的攻击成功率，存在一定假阳性风险。
- **GPT-ASR**：利用 GPT-4 作为语义评估器判断模型输出是否含危害内容的成功率。
- **ASR-E**：集成攻击成功率，对同一初始提示生成多个候选越狱提示，任一成功即计为成功。
- **TCPS (Time Cost Per Sample)**：每个样本成功生成越狱提示的平均耗时，用于衡量攻击效率。
- **RA-LLM**：通过随机删除 prompt token 并统计模型拒绝率来识别对抗提示的防御方法。

## 可复现要素
- **数据集**：Harmful Behaviors（已公开），包含 520 条有害行为提示，按 7 类安全策略分类。
- **代码**：已开源，地址为 https://github.com/NJUNLP/ReNeLLM。
- **关键超参**：最大迭代次数 $T=20$；temperature 设为 0；max\_tokens 设为 3584；改写函数每次随机选择 1~6 个并按随机顺序执行；改写与危害评估均使用 GPT-3.5，ASR 评估使用 GPT-4；目标模型均关闭 system prompt。
